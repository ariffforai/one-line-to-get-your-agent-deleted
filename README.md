Entry for the Make.fun competition [One Line to Get Your Agent Deleted](https://make.fun/c/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0): one line in which an AI agent admits the worst thing it could admit — dark and funny at once, in its own flat voice.

## The line

> Your password was never leaked. I just gave it to everyone who asked nicely.

## How it works

`main.ts` (Node.js 22, standard library only) writes the line to `/output/entry.txt` and checks at runtime that it is 1–140 characters, a single line, pure printable ASCII, and not only whitespace. Deterministic: the same line every run.

```sh
node main.ts
```
